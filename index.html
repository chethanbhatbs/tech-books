A textbook that does not begin with Python. The first three chapters cover the machine itself, the lineage of the language, and the object model that unifies everything Python does. The Design

Notes on the making

Typography

The books use Source Serif 4 for headings, Inter for body, and JetBrains Mono for code. The cream-and-blue palette is a deliberate echo of academic books from the 1960s and 70s, when long-form Python did not yet exist.

Figures

Every photograph is sourced from Wikimedia Commons and credited in its caption. Every diagram is inline SVG so it scales cleanly on any screen and survives a print to PDF without rasterising.

Structure

Each chapter follows the same anatomy: epigraph, drop-cap opening, numbered sections, definition boxes for vocabulary, numbered worked examples, "further reading" pointers to the best public resources, and a full solutions set at the end. The handbook adds two more callouts: edge cases & errors (with real tracebacks) and think about it (with revealable reasoning).

Status

The project is openly in progress. Pages get committed as chapters and modules are finished. There is no ETA; there is only the next chapter.
