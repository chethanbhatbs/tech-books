# The Claude Handbook

A three-level guide to Claude: install and use it, run Claude Code and connect your tools, and understand how MCP works inside. Hand-drawn diagrams throughout, plus things to click: a folder explorer, an effort slider, a "which layer?" quiz, a product chooser and a printable cheat sheet.

## How to read

### 1 · In your browser
Open **[https://chethanbhatbs.github.io/claude-handbook/](https://chethanbhatbs.github.io/claude-handbook/)**, or click any chapter link above. It reads like a book: one chapter per page, Previous and Next at the bottom (or the arrow keys), and a side menu with search that ticks off the chapters you have opened. The switch in the top right changes between light and dark mode.

### 2 · On your phone
The page reflows for phone screens. Wide diagrams and tables scroll sideways inside their own box.

### 3 · Offline
Download [`index.html`](index.html) (it is one self-contained file) and open it in any browser. Fonts and the diagram library load from the internet the first time, so the very first open needs a connection.

## About the content

Facts were checked against official Anthropic, Claude Code and MCP docs on 14 Oct 2026; effort levels, permission modes, the folder structure and settings precedence were checked on 23 Oct 2026. Products change quickly; each chapter names its source.

## Source and design

- `index.html` is the page itself, served by GitHub Pages. Every push to `main` redeploys it.
- `src/` holds the editable source.
- Diagrams are drawn with [rough.js](https://roughjs.com) in the Excalidraw style, using the Virgil font from [Excalidraw](https://github.com/excalidraw/excalidraw) (SIL Open Font License). Code examples are coloured with [Prism](https://prismjs.com).
